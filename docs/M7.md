# M7 — combat

`DESIGN.md` section 13: tanks, jets, saucers, bullets, collisions, death
and sortie cycle. This program does that and stops. Not SN76496 (M8). Not
sortie banners or win/lose art (M9). Not the finished game.

M6 put hostages on M5 flight. M7 is that plus the original combat from
`choplifter.s`. Attended runs open on the same BIOS mode 3 title as M5/M6,
then mode 8.

1. **Tanks.** Up to four. Spawn past the fence (`FENCE_X`), level 0 only
   tanks. They roll, aim five cannon angles, and fire shells. Shells that
   land ignite intact barracks (`houseStates`) so the remaining 16 can run.
2. **Chopper fire.** Airborne, not dying, cap five shots. Button 0 / `/`
   (keyboard). Physics from `initBulletPhysics` / `bulletVelocityTable`.
   Hits tanks, jets, saucers, hostages, and houses.
3. **Jets and saucers.** `CURR_LEVEL` (ticks on each pad unload, cap 3):
   level 0 tanks; 1 adds jets; 2+ adds saucers. Jets use the 25
   `jetMaster` frames, even-X only. Saucers chase and can ram.
4. **Death / sorties.** Crash-speed or ordnance sets dying. Airborne death
   shows explosion frames; on the ground a type-2 sink/rubble entity
   plays, then `DEATHTIMER` (+6 per tick until bit 7) starts the next
   sortie. Three lives. 64 rescued or 64 killed ends the run (no M9 art).
5. **Reuse.** JrConfig pages, `blit_rle`, even-width dirty lists, M4 camera,
   M5 physics / title / joystick-1-only, M6 hostages. BROWN ground. 20 Hz
   sim. No full-screen copy.

Ground colour stays BROWN. Video `stosw` is 44.8 ms/screen on hardware (M1);
this program never fills a page.

## Building

Same toolchain as [docs/M1.md](M1.md). From PowerShell:

```
. .\setenv.ps1
cmd /c "wmake NASM=lib\repos\nasm\nasm-3.02\nasm.exe"
```

That builds `build\m1.exe` through `build\m7.exe`. There is no `wmake run-m7`;
do not launch DOSBox from the makefile for this visual.

`GROUND=BROWN` (default) or `GROUND=PINK`. Clean first when changing it.

Combat RLE is generated by `python tools/build_sprites.py` into
`src/sprdata_combat.c` (chopper RLE in `src/sprdata_rle.c`, scenery in
`src/sprdata_world.c`, hostages in `src/sprdata_host.c`).

## Title and controls

Same as [docs/M5.md](M5.md): Joystick default, **C** calibrate, **K** WASD
help, SPACE to fly, Esc quits. Joystick 1 only. Keyboard WASD / `.` rotate /
`/` fire. Stick button 0 fires (airborne, cap 5).

## How to play (attended)

A human has to watch. The escape hatch is **Esc** (title → DOS, play → DOS).
Do not start an emulator until someone is in front of it.

### Real PCjr

`DEVICE=JRCONFIG.SYS /V64 /L`, pages 6 and 7. Copy `build\m7.exe`. Stick on
**joystick 1**. No `/force`.

```
M7
```

Centre the stick, SPACE to fly. **Up is thrust.** Fly **left** from the pad
past the fence. Tanks spawn in the field. Eight hostages are already out
by the far house; shells set the other barracks alight.

`/force` on an emulator whose model byte is not `FDh`. `/batch` skips the
title; `/frames=N` caps retraces. **K** then WASD if there is no stick.

### What a pass looks like

- Title then chopper on the **base pad**, facing right, HUD `K00 A00 R00`,
  and **FIRST SORTIE** in the sky for about two seconds.
- Past the fence: red tanks with cannons; fire produces bullets; a tank
  hit becomes an explosion.
- A shell on an intact house switches it to the burning barracks art and
  hostages start to leave.
- A crash-speed landing or a shell on a grounded chopper plays explosion /
  sink, then a fresh chopper on the pad (aboard hostages count as killed).
- Three such deaths end the run. 64 R or 64 K also ends it.
- Camera lead 80/240, mountains slower than scenery, BROWN ground.
- No trail, no flicker, no full-screen flash on scroll.

A fail is tanks that never appear, fire that does nothing, death that
still only teleports with no explosion, a full-screen copy, or Esc not
restoring DOS.

## What this does not do

- Joystick is still “works, not perfect”; this milestone does not retune it.
- No SN76496 (M8). No BCD bubbles / sortie banners / Broderbund win-lose (M9).
- Crush still has no dying-hostage sprite on the skids (the art is in the
  combat set for wreckage).
- Playdate rope is out of scope.
- Jet banking uses the 25 even-X frames; it is not a cycle-accurate port of
  every `jetYVelocityTables` nibble yet.
