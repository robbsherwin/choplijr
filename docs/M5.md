# M5 — flight

`DESIGN.md` section 13: chopper physics, 11-step tilt state machine, joystick
control. This program does that and stops. Fire is a stub (M7). Not hostages,
not the game.

M4 put the world on screen: camera lead 80/240, mountain parallax, BROWN
ground, barracks / fence / base, `blit_rle` chopper. M5 is that world with
the original helicopter instead of a stub flyer. Attended runs open on a
BIOS mode 3 title, then switch to mode 8 when play starts.

1. **Title (BIOS mode 3, 80 columns).** Default control is Joystick. **J**
   selects Joystick (does not open a help screen). **K** selects Keyboard and
   shows the WASD help screen; SPACE on help returns to the title. **C**
   opens the calibrate box (BIOS mode 3). SPACE or a stick-1 button there
   snapshots rest and returns with Joystick selected; Esc cancels. Calibrate
   is never cyan. SPACE on the title starts the game (mode 8, existing
   JrConfig pages and 20 Hz loop). Esc on the title quits to DOS. Stick
   button does **not** start from the title. **C** does not start the game.
2. **Physics** from `choplifter.s`: 16-bit VX/VY, the `$7418` / `$7424`
   acceleration tables, gravity at `ZP_ACCELY` = 8, thrust 0–15, ground
   settle, crash-speed reset to the pad (no explosion art — that is M7).
3. **11-step tilt.** `ZP_TURN_STATE` runs −5 (full left) through 0 (head-on)
   to +5 (full right), one or two steps per sim tick toward `CHOP_FACE`.
   Side view uses the 11 pitch frames from ACCELX; mid-turn uses the 5
   head-on rotation frames. Rotate must be airborne, as in the original.
4. **Joystick primary** (title default). Analog axes mapped to the Apple
   paddle 0–255 scale (each side of rest uses the full 0–255 range), then the
   original nibble tables (`ZP_STICKX` −5..+5, `ZP_ACCELY` 0–15). On BIOS model `FDh` (a real PCjr) the default is
   **port 201h**, using the counting loop from Paku Paku 1.6a
   `SOURCE/JOYSTICK.PAS` (`joyStick1Axis` only): CLI, OUT 201h,
   count while axis bits stay **high**, timeout `CX=$7FFF`. Original PCjr
   BIOS does not implement INT 15h AH=84h (Ralf Brown: XT after 1/10/86, AT,
   PS/2). `/int15` forces that BIOS call; `/port201` forces the counting
   loop. **Joystick 1 only** (IBM first connector / Paku stick A): bits 0,1
   for X/Y. Stick B (bits 2,3) is not read. Buttons from port `201h`
   (active low; stick 1 in bits 4–5). Stick 2 is unused.
5. **Keyboard** follows `jrpiano3.asm` (INT 9, `IN 60h`, make/break `kbd[]`,
   chain, empty BIOS buffer) plus PCjr **INT 48h** (NMI intercept; scan in
   AL). A one-tick make pulse covers a make+break in one retrace. **No
   analog** in Keyboard title mode. WASD are digital extremes only (W
   thrust/up, S down, A/D tilt/translate — same signs as Apple 0). `.`
   rotate, `/` fire stub. Arrows extra. Space does not fire (it started the
   game). In **Joystick** mode, Paku 201h is unchanged and WASD still
   override analog. Ctrl-A / Ctrl-V invert X / Y, as in the original. Esc
   quits play.
6. **20 Hz sim**, every third vertical retrace. The screen may still flip at
   60 Hz. Constants stay verbatim. Present-rate timings are not claimed.

Deadzone: **±16 on the 0–255 Apple scale around 128** (~12.5% throw) after
each side of rest is scaled onto the full Apple range (raw 0 → Apple 0,
timeout → Apple 255). The older `(raw-center)*128/center` map only had a
full 128 Apple units toward 0; the high side was often a few tens of units
and the deadzone ate stick down/right. Raw rest is captured on the calibrate
screen (SPACE or stick button, 8-sample average) and again when SPACE starts
play (Joystick mode only). The X table then has its own one-nibble centre
bucket (inverted raw 112–127 → stick 0). Leave the stick centred, then
SPACE. `/stick` prints a snapshot before the title and `min/max/now` after
Esc from play.

Ground colour stays BROWN. No full-screen copy. Video `stosw` is 44.8
ms/screen on hardware (M1); this program never fills a page.

## Building

Same toolchain as [docs/M1.md](M1.md). From PowerShell:

```
. .\setenv.ps1
cmd /c "wmake NASM=lib\repos\nasm\nasm-3.02\nasm.exe"
```

That builds `build\m1.exe` through `build\m5.exe`. There is no `wmake run-m5`;
do not launch DOSBox from the makefile for this visual.

`GROUND=BROWN` (default) or `GROUND=PINK`. Clean first when changing it.

## Title (BIOS mode 3, 80×25, rows 0–24)

White is attribute `0x0F` on black. Light cyan (the selected control’s first
letter) is `0x0B`. Calibrate is never cyan.

| Row | Col | Text |
|---|---:|---|
| 9 | 34 | `CHOPLIFTER!` (12 chars, white) |
| 10 | 34 | `for IBM PCjr` (12 chars, white) |
| 11 | | *(blank)* |
| 12 | 24 | `Joystick   Calibrate   Keyboard` (31 chars; three spaces between words) |
| 13 | | *(blank)* |
| 14 | 30 | `Press SPACE to play` (19 chars, white) |

On row 12, **J** of Joystick is light cyan when Joystick is selected (default);
the rest of that word is white. **K** of Keyboard is light cyan when Keyboard
is selected; then the whole of Joystick is white. Calibrate stays white.

### Keyboard help (after **K**)

| Row | Col | Text |
|---|---:|---|
| 8 | 39 | `W` |
| 9 | 37 | `A S D` (A at 37, S at 39, D at 41) |
| 12 | 29 | `WASD moves the chopper` |
| 13 | 24 | `. turns the chopper and / shoots` |
| 22 | 28 | `Press SPACE to continue` |

All help text is white. SPACE returns to the title with Keyboard selected.

### Calibrate (after **C**)

BIOS mode 3, 80×25, same white (`0x0F`) as the title. One `*` is joystick 1
(first connector, bits 0,1). Rest maps to the box centre. Low throw
is raw near 0; high throw is `STICK_LIVE_MAX`, the same high side as
`apple_from_raw`. The star has **no** extra deadzone. Live update uses the
Paku 201h loop on stick 1 only (or `/int15` DX=1). Min/max while the star
moves are tracked for later scale and do **not** change flight yet.

The box is ASCII `+` `-` `|`: **33 columns × 13 rows** including the border
(**31 × 11** inner). Origin row 6, col 23. Rest `*` is inner (15, 5) →
screen col 39, row 12.

| Row | Col | Text |
|---|---:|---|
| 6 | 23 | box top `+---` … `---+` (33 chars) |
| 7–17 | 23 | `\|` + 31 spaces + `\|` |
| 18 | 23 | box bottom |
| 20 | 17 | `Center the stick, then SPACE or button to save` (46 chars, white) |
| 21 | 34 | `Esc cancels` (11 chars, white) |

| Key | Effect |
|---|---|
| Stick | Moves the `*` (joystick 1 only). |
| **SPACE** or stick-1 button | 8-sample average into `stick_cx0` / `stick_cy0`, debounce, back to title with Joystick selected (cyan J). |
| **Esc** | Cancel. Rest is unchanged. Back to title. |

### Title keys

| Key | Effect |
|---|---|
| **J** | Select Joystick (cyan J). Does not open a stick-help screen. |
| **K** | Select Keyboard, leave title, show WASD help. |
| **C** | Open the calibrate box. Does not start the game. Calibrate stays white. |
| **SPACE** | On help: back to title. On calibrate: save rest, back to title with Joystick. On title: start the game (Joystick or Keyboard). |
| **Esc** | On calibrate: cancel (rest unchanged), back to title. On title: quit to DOS (does not fly). |

Joystick button to start is later, not this milestone.

| Input | Effect |

| Joystick 1 Y | Thrust 0–15 (up = full thrust, down = none, centre ≈ gravity 8) |

## Running (attended)

A human has to watch. The escape hatch is **Esc** (title → DOS, play → DOS).
Do not start an emulator until someone is in front of it.

### Real PCjr (the point)

`DEVICE=JRCONFIG.SYS /V64 /L`, pages 6 and 7. Copy `build\m5.exe`. Plug in a
PCjr stick on **joystick 1** (first connector). No `/force`. Do not use
the second connector.

```
M5
```

No switch. Port 201h on model `FDh`; **joystick 1 only** (bits 0,1). Diagnostic
text prints stick 1 raw counts plus INT 15h (expect CF on original PCjr BIOS),
then BIOS mode 3 title. **C** is the calibrate box (centre, SPACE or stick-1
button to save rest). Centre the stick, SPACE to fly. **Up is thrust**
(lifts off); **down cuts thrust** (centre ≈ gravity). Left/right tilts and
translates. After Esc from play, mode 3, which control was used, and the
pass-by-eye sentence.

`M5 /stick` if the next run still looks dead: a snapshot before the title,
rest captured at SPACE, then after Esc from play `/stick 1 x min/max/now … y
…` (min and max must differ if the pots were read). `/port201` and `/int15`
are overrides only. `/batch` skips the title (Joystick, then frames).

### DOSBox-X (keyboard or a host stick)

`conf/pcjr-dev.conf` and `conf/pcjr-128k.conf` already have
`joysticktype = 2axis`. Do not launch them from the makefile. When someone
is watching, mount `build\` as `C:` and:

```
M5 /force
```

`/force` because the emulator model byte is not `FDh`. **K** then WASD on
the title if there is no host stick. Auto on a non-PCjr tries INT 15h then
port 201h. `/batch` skips the title; `/frames=N` caps retraces (`/batch`
defaults to 1800 if you omit `/frames`).

### What a pass looks like

- Title in 80-column mode 3: `CHOPLIFTER!`, cyan **J**, **C** opens the
  calibrate box (one `*` at rest in the centre), SPACE starts.
- Then the chopper on the **base pad**, facing right, rotors spinning.
- **Up** (stick, W, or arrow) lifts off; **down** (stick, S, or arrow) cuts
  thrust and descends. Without thrust it settles.
- **Left/right** (stick, A/D, or arrows) tilts through the side pitches and
  translates both ways; camera lead 80/240, mountains slower than the
  scenery, BROWN ground, HUD rows 0–7 untouched.
- Airborne, **button 1 / Alt** (Joystick) or **`.`** (Keyboard) rotates
  through head-on (11 steps), then the other side. Cannot rotate on the
  ground.
- No trail, no flicker, no full-screen flash on scroll.
- A hard landing at crash speed puts you back on the pad (no M7 explosion).

A fail is a stick that does nothing on real hardware, tilt that skips
straight from −5 to +5, a camera glued to the chopper (no lead), a
full-screen copy each frame, or Esc not restoring DOS.

## What this does not do

- Calibrate snapshots rest only. Throw min/max are stored but do not change
  flight scale yet.
- Joystick 1 only (first connector). Stick 2 is unused.
- Joystick button does not start from the title (SPACE only). On the
  calibrate box it saves rest (stick-1 buttons).
- No bullets (fire is latched and ignored). Death is a pad reset, not type
  1/2 entities (M7).
- No hostages (M6). No SN76496 (M8). No HUD counters (M9).
- INT 15h vs port 201h is not timed on hardware. Paku is the stick reference,
  not a BIOS measurement.
- Playdate is out of scope.
