## Building

Same toolchain as [docs/M1.md](M1.md). From PowerShell:

```
. .\setenv.ps1
cmd /c "wmake NASM=lib\repos\nasm\nasm-3.02\nasm.exe"
```

That builds `build\m1.exe` through `build\m10.exe`. There is no `wmake run-m10`;
do not launch DOSBox from the makefile for this visual.

`GROUND=BROWN` (default) or `GROUND=PINK`. Clean first when changing it.

## Title and controls

Same as [docs/M5.md](M5.md): Joystick default, **C** calibrate, **K** WASD
help, SPACE to fly, Esc quits. After SPACE, four logo screens; SPACE skips
one. Joystick 1 only. Keyboard WASD / `.` rotate / `/` fire. Stick button 0
fires (airborne, cap 5). **Ctrl-S** mutes.

`/ztimer` samples sim_frame 4 (chopper still on the pad, both dirty lists
live). `/ztimer=N` picks another tick. Interrupts are off for that present;
do not touch the keyboard — the PCjr scans it from NMI, which CLI cannot
hold off.

## Hardware pass

A human has to watch **and listen**. Copy `build\m10.exe` to the PCjr the
same way as M1 (`J:\GAMES\CHOPLIJR\` on the last GO). JrConfig
`DEVICE=JRCONFIG.SYS /V64 /L`, pages 6 and 7. RGB monitor.

Escape hatch is **Esc** (title or logos → DOS, play → DOS). Do not start
an emulator until someone is in front of it; the hardware run is the one
that fills this list.

| Check | What a pass looks like |
|---|---|
| Pages | Same pair as M1: **6 and 7**. Startup prints the chosen pair. |
| Stick 1 | Analog throw moves the chopper; button 0 fires airborne. `/stick` prints rest and throw after Esc. |
| SN76496 | Start medley on SPACE→play; cannon, shells, crash rumble. Port `61h` bits 5–6 must be set (`snd.c`); DOSBox ignores that gate. |
| Sky dither | Horizon haze→dark→black Bayer bands on RGB. Judged by eye, not a number. |
| WORKSET | After Esc, restore / rle blit min/avg/max in bytes. Compare to section 7's ~3000 / ~320 / ~1500 / ~3000 analysis — do not treat a match as proof. |
| `/ztimer` | `M10 /ztimer /batch /frames=60` with **no keys** during the sample. Capture stdout to a numbered file under `J:\GAMES\CHOPLIJR\` (this cut is `M10-01.LOG`). Overflow (~54 ms) means the interval is past the Zen window; the tick count is then meaningless. |

Redirected hardware capture (graphics still run; the report prints after
mode 3 returns):

```
M10 /ztimer /batch /frames=60 > M10-02.LOG
```

Do not redirect M10 over `M1.LOG`. The M1 GO rates are in `DESIGN.md`
section 2; that filename is for an M1 re-run if you ever want a new
throughput file.

`/force` only on an emulator whose model byte is not `FDh`. Emulator
`M10.LOG` is not the hardware log.

Use `conf/pcjr-128k-m10.conf` (`m10.exe /force`) only as a smoke test of
the counters and the `/ztimer` path.

Emulator audio and frame times are a smoke test only.
