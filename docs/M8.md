# M8 — sound

`DESIGN.md` section 9 and 13: SN76496 effects with voice stealing. This
program does that and stops. Not sortie banners or win/lose art (M9). Not
the finished game.

M7 put combat on M6 hostages. M8 is that game plus the original's play
events on the PCjr sound chip. Attended runs open on the same BIOS mode 3
title as M5–M7, then mode 8.

1. **Chip.** TI SN76496 at port `0xC0`. Port `0x61` bits 5–6 are set so a
   real PCjr is not silent (jrpiano3; DOSBox ignores that gate). Back-to-back
   `out`s; the chip READY pin inserts the wait states.
2. **Voices.** Three tone channels with jrpiano3 stealing: retrigger the
   same effect's voice, else round-robin. Noise is a fourth channel for
   shells, missiles, explosions, and the crash rumble.
3. **Effects.** Apple `playSound` is X delay / Y clicks / A decay, blocking.
   Here `N = X<<2` (1..1023) and streams run on the 20 Hz sim tick. Cannon
   fire, tank shell, jet missiles, boarding triplet, rescue beep, hostage
   death ditty, house ignite, explosions, crash rumble, three-note start
   medley. No background music.
4. **Ctrl-S.** Toggles like `PREFS_SOUND` (`$FF` on, `$00` mute). Does not
   dump thrust (S alone still sits). Mute silences the chip immediately.
5. **Reuse.** M7 combat, JrConfig pages, `blit_rle`, BROWN ground, 20 Hz
   sim. No full-screen copy.

Ground colour stays BROWN. Video `stosw` is 44.8 ms/screen on hardware (M1);
this program never fills a page.

## Current status

**Compiling increment.** `build\m8.exe` is 56,686 bytes. Attended pass:
hear the start medley on SPACE, cannon on fire, boarding triplet, tank
shells, explosion noise, crash rumble; Ctrl-S mutes.

This program does **not** time dirty-rect or blit byte counts. Emulator
audio is a smoke test. DOSBox does not require the port `61h` gate; a real
PCjr does. Do not treat an emulator clock as hardware.

Quoted from `DESIGN.md` section 2 (real PCjr, `J:\GAMES\CHOPLIJR\M1.LOG`):
video `stosw` is **2803 ns/byte, 44.8 ms/screen**. A 16,000-byte fill or
copy does not fit a 50 ms 20 Hz frame.

## Building

Same toolchain as [docs/M1.md](M1.md). From PowerShell:

```
. .\setenv.ps1
cmd /c "wmake NASM=lib\repos\nasm\nasm-3.02\nasm.exe"
```

That builds `build\m1.exe` through `build\m8.exe`. There is no `wmake run-m8`;
do not launch DOSBox from the makefile for this visual.

`GROUND=BROWN` (default) or `GROUND=PINK`. Clean first when changing it.

Sound is `src/snd.c` / `src/snd.h`. Apple X/Y/A → period mapping is
documented in `tools/build_sound.py` (the tables in `snd.c` are the
checked-in streams).

## Title and controls

Same as [docs/M5.md](M5.md): Joystick default, **C** calibrate, **K** WASD
help, SPACE to fly, Esc quits. Joystick 1 only. Keyboard WASD / `.` rotate /
`/` fire. Stick button 0 fires (airborne, cap 5). **Ctrl-S** mutes.

## How to play (attended)

A human has to watch **and listen**. The escape hatch is **Esc** (title →
DOS, play → DOS). Do not start an emulator until someone is in front of it.

### Real PCjr

`DEVICE=JRCONFIG.SYS /V64 /L`, pages 6 and 7. Copy `build\m8.exe`. Stick on
**joystick 1**. No `/force`. If the picture is right and there is no audio,
port `61h` bits 5–6 did not take — that is the jrpiano gotcha.

```
M8
```

Centre the stick, SPACE to fly. **Up is thrust.** You should hear the start
medley as the pad appears. Fire, board, take a shell, crash.

`/force` on an emulator whose model byte is not `FDh`. `/batch` skips the
title; `/frames=N` caps retraces. **K** then WASD if there is no stick.

### What a pass looks like

- Same visuals as [docs/M7.md](M7.md).
- Start medley on entering flight. Cannon blip on fire. Boarding triplet
  (once per tick). Rescue beep on pad unload. Tank shells and explosions
  on the noise channel. Crash rumble that decays. Ctrl-S silence, Ctrl-S
  again restores (next effect, not a resume).
- Overlapping fire + boarding still both audible (voice steal, not a
  single blocking speaker loop).

A fail is silence on a real PCjr with the picture running, effects that
block the sim, or Esc not restoring DOS.

## What this does not do

- Joystick is still “works, not perfect”; this milestone does not retune it.
- No BCD bubbles / sortie banners / Broderbund win-lose (M9).
- Title and banner PVM music is optional in `DESIGN.md` and is not here.
- Playdate rope is out of scope.
- Apple `playSound` is a blocking click loop; these are SN76496
  translations, not cycle-accurate speaker dumps.
